Docs and deploy API

Everything you need to ship a static site from your terminal or from GitHub Actions.

1. Create a token

Log in, open Account and create an API token. Copy it right away. It is shown only once.

2. Deploy a ZIP with curl

zip -r site.zip . -x ".git/*"
curl -X POST {{ cfg.home_url }}/api/v1/sites/YOURSITE/deploy \
  -H "Authorization: Bearer $NESTHOST_TOKEN" \
  -F "zip=@site.zip"

Response: {"ok": true, "files": 12, "url": "..."}

3. Deploy from GitHub Actions

Save the token as a repository secret named NESTHOST_TOKEN.

name: deploy
on: { push: { branches: [main] } }
jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: zip -r site.zip . -x ".git/*" ".github/*"
      - run: |
          curl -fsS -X POST {{ cfg.home_url }}/api/v1/sites/YOURSITE/deploy \
            -H "Authorization: Bearer ${{ '{{' }} secrets.NESTHOST_TOKEN {{ '}}' }}" \
            -F "zip=@site.zip"

List your sites

curl {{ cfg.home_url }}/api/v1/sites -H "Authorization: Bearer $NESTHOST_TOKEN"

Contact forms

Every site has a private form address (see the site page). Post any HTML form to it. Add a hidden _gotcha input as a spam trap. You can also post JSON with fetch.

fetch("{{ cfg.home_url }}/f/YOUR_FORM_TOKEN", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ email: "a@b.com", message: "Hello" })
}).then(r => r.json()).then(console.log);

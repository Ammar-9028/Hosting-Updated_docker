Frequently asked questions

Do I get a real .com domain for free?

No. A .com or .in domain is only registered when the registry is paid, so nobody can give it away for free. You get a free subdomain here. See the domain guide for real-domain options.

How do I connect my own domain?

Open your site, add the domain, point its DNS A record to the IP shown, then click Verify.

What kind of websites can I host?

Static sites only: HTML, CSS, JavaScript, images and fonts. Use the form inbox for contact forms. No PHP or Node.

Can I deploy automatically from GitHub?

Yes. Create an API token in your account and call the deploy API from GitHub Actions. See the docs.

Is my data safe?

Passwords are hashed. Site files are public by design, so never upload secrets.
